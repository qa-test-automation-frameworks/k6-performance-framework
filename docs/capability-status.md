## Feature currency review — 2026-10-16

The framework and CI pin k6 `2.0.0`. The decision below compares current code with the official
k6 documentation and v2 release notes; it does not imply that every experimental or cloud feature
is required.

This is a feature decision record, not evidence that the current baseline is universally stable. The
p99 dispositions diverged across exact full-profile runs: `38925775044` passed, while `38933904782` failed every p99 comparison despite improved p95 values. The controlled controlled latency injection proves sensitivity, but its lower request rate does not calibrate this full profile. Preserve both results until matched repeated runs separate target, runner and generator effects; no thresholds or baseline values are relaxed here.
