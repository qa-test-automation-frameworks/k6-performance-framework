# v0.1.0

Initial reviewed release of the k6 Performance Framework.

## Highlights

- Strict TypeScript service layer for RealWorld auth, articles, comments, profiles, and tags.
- Smoke, load, stress, spike, soak, and breakpoint workloads.
- Stable request tags, runtime token distribution, target safety guards, and generated fixtures.
- Aggregate JSON/Markdown summaries and baseline regression checks.
- InfluxDB, Grafana, OpenTelemetry, and custom k6 Docker tooling.
- PR smoke, main load, scheduled soak, quality, security, and Pages workflows.
- CycloneDX SBOM generation, npm audit, OSV scanning, and pinned GitHub Actions.

## Known Limitations

- Shared GitHub runners introduce performance variance; the relative regression tolerance is 20%.
- The public API is used only for short read-only compatibility checks.
- Authenticated CI load is excluded until a managed token lifecycle is introduced.
