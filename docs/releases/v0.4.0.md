# v0.4.0

This release strengthens execution safety, failure reporting, regression detection, observability
validation, workload configuration, and cross-platform operation.

## Verification

- Functional check failures are enforced by every workload and reflected in generated summaries.
- Sustained non-local traffic requires explicit authorization.
- Main and regression workflows require a reviewed three-run measured baseline.
- Observability validation exercises Grafana provisioning, InfluxDB ingestion, and Prometheus
  export.
- The release workflow publishes the CycloneDX SBOM and checksums with the tagged release.

The published tag contains the reviewed load baseline and supply-chain assets. Full advanced
workload artifacts were not retained as a publication prerequisite for this historical release.
Later releases close that process gap by blocking publication on full stress, spike, soak, and
breakpoint jobs.
